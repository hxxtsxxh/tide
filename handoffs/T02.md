## What exists (all behind the ONE guard `runGuarded`; origin -> body cap -> schema -> source policy / snapshot verify -> kill switch -> atomic quota -> execute)
- `src/lib/search/telem.ts` `TelemClient`: real `POST router.telem.ai/v1/search|fetch` (Bearer `TELEM_API_KEY`).
  Search: `auto_routing:accuracy`, `providers.include=[brave,tavily]` (max 2), `include_domains` = source hosts.
  Fetch: one batch of <=5 distinct URLs, `inline_content`, `no_cache:true` on refresh. Each result judged
  individually (status/http_status/empty/truncated); returned `url` AND `canonical_url` re-checked against the
  host policy. Counters: queries<=2, pages<=5, HTTP attempts<=6. 401/402/403 never retried; ONE transient retry
  (408/425/429/5xx/network) only if >=5 s remain. `request_payload` (contains provider tokens) is never read.
  Telem quirk observed live: boolean `cached`/`age_seconds` is authoritative; `cache_state` says "cached" even
  for `no_cache` reads — trace/`cache_state` use the boolean.
- `src/lib/model/client.ts`: Anthropic `/v1/messages` (x-api-key + `anthropic-version: 2026-10-21`) or OpenAI
  `/v1/responses`; `max_tokens` 2048; every attempt incl. the one retry is `budget.take()`n; `capBudget` gives lower
  legacy limits. `extract.ts`: prompts (page text fenced as untrusted data) + zod output schemas.
- `src/lib/server/research.ts`: `discover`, `buildBoard`/`createBoard`, `refreshBoard`, `openSnapshot`.
  Facts need a quote that occurs literally (whitespace-normalized only) in fetched text; excerpt = windows around
  quotes (quotes are literal substrings of `source.excerpt`); unverifiable -> fact `unknown`, dependents `unknown`.
  Answers with no valid dependency are dropped. Dependencies are marked `dependency_review:'proposed'`.
  Cross-source same-key different-value -> `conflicting`. Server-side bookkeeping (fact keys, uses_requirements)
  rides INSIDE the HMAC snapshot (`meta`); the browser treats `snapshot` as opaque.
- Refresh semantics: `force=true` re-reads all sources with `no_cache`. unchanged hash -> no model call, answers reused
  with original `observedAt`; changed hash -> one facts-only extraction, match by (source,key); value change ->
  reverse closure recomputed in one rewrite call; vanished fact -> `unknown`; failed fetch -> source `failed`, last good
  hash/excerpt kept, dependents `unknown`, nothing falsified; extraction/rewrite failure -> `stale`/`unknown`, never fresh.
  `force=false`+requirements: no Telem call; only answers the model flagged `uses_requirements` (+ dependents) are
  recomputed; revision kind `requirements_edit` ("not an external change"). Stale answers are retried by the next refresh.
  No-op edits (force=false, same requirements) -> 400 before quota. Snapshot TTL 7 days; tampered/expired/other key ->
  409 REVALIDATION_REQUIRED before quota; host no longer allowed -> 422 SOURCE_NOT_ALLOWED.
- `src/lib/server/operations.ts`: `execute` for /api/boards (201), /api/boards/refresh, /api/discover, /api/refresh.
  `guarded.ts` (T01 file, in my scope) gained: `prepare` receives `secrets`; `GuardDeps.fetchImpl` test seam.

## Agent / native interface (for T05A / connector)
Native calls use the same routes. Required: `Origin` equal to the public origin (CSRF compatibility only — NOT identity)
and the persistent signed cookie `ripple_visitor` (value `<22-char id>.<HMAC>`; minted by `GET /api/session` or by the
first billable request via `Set-Cookie`; HttpOnly, SameSite=Strict, Path=/, 180 days). Persist and resend it. No service
keys, no bypass; quota/snapshot/URL/body/response bounds are identical to browsers. A forged cookie is replaced by a
server-minted one (it cannot choose its identity); failed upstream calls still consume quota.
