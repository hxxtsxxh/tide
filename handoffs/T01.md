# T01 handoff — contracts frozen, deployable shell

## What exists
- Next.js 16.4.6 / React 19.3.1 / TypeScript 6.0.3 / zod 4.6.7, npm lockfile, Node >=22.18
  (tests use native TS type stripping, so `src/lib/**` imports use explicit `.ts` extensions and
  no TS-only runtime syntax: no enums or parameter properties).
- Scripts: `dev`, `start` (both accept `--hostname H --port P`), `check` (tsc), `test`
  (`node --conditions=react-server --test`, non-watch), `build`, `evaluate`.
- `npm run evaluate -- --mode live|fixture --output F` wraps the prepared
  `.searchhack/context/evaluation/run.py` (honors SEARCHHACK_BASE_URL and IMPLEMENTED-SCOPE.json
  case IDs) and writes {schemaVersion,project,mode,executedAt,caseCount,passed,failed,skipped,cases,
  metrics:{baselineStatus},limitations}. The raw runner report sits next to it (`*.raw-<mode>.json`).

## Frozen contracts (src/lib/contracts — integrator-owned, do not fork)
- `legacy.ts`: zod mirrors of contracts/{request,response,error}.schema.json (key sets are tested
  against the JSON files), plus HealthBody.
- `board.ts`: PUBLIC_LIMITS, BODY_LIMITS, ERROR_CODES, DEFAULT_SOURCE_HOSTS, strict
  Create/Refresh/Discover requests, Board/BoardEnvelope/DiscoverResponse, SignedBoardState (the
  payload inside `snapshot`), BoardArchive `ripple-board-v1` (snapshot nullable) and `parseArchive`
  (1 MiB cap, rejects __proto__/constructor/prototype keys and duplicate IDs; cycle checks belong to
  the domain layer).
  Optional answer fields `dependency_review: 'proposed'|'reviewed'` and `observedAt` were added
  for the proposed-vs-reviewed edge UI and reuse timestamps.
- `storage.ts`: IndexedDB `ripple` v1; stores boards (keyPath id, BoardRecord with localRevision
  for expected-revision writes), revisions (keyPath [boardId,revisionId], index byBoard), and meta
  (`activeBoardId`). Trust values: 'observed' | 'archived-unverified'.
- `testids.ts`: every selector from public-beta/API.md (tested against that file).
- `src/lib/demo-policy.ts`: `SIMULATION_LAB_ENABLED = true`, `DEFAULT_PRODUCT_MODE = 'live'`.

## Server (src/lib/server)
- `guards-core.mjs`: verbatim copy of public-beta/reference/guards.mjs. `guards.ts` is the
  server-only wrapper. The reference regression suite runs as tests/guards.test.mjs.
- `guarded.ts` `runGuarded(req, spec)` is the ONE entrypoint for /api/boards, /api/boards/refresh,
  /api/discover and /api/refresh. Order: Origin === public origin (Host + x-forwarded-proto, because
  Next rewrites req.url's 127.0.0.1 to localhost) -> body read with a streaming byte cap -> strict zod ->
  `prepare` (source policy / fixture gating) -> `execute` missing ? 501 : kill switch
  (RIPPLE_PUBLIC_BETA=false -> 503) -> quota/signing config (503 QUOTA_UNAVAILABLE) ->
  Telem/model config (502) -> signed visitor cookie (minted if missing or forged) -> atomic
  QuotaStore.reserve (outage 503, denial 429 with Retry-After) -> execute(body, ctx). ctx provides
  `budget` (RunBudget: 6 attempts, 45 s), `signal` (45 s abort), `secrets` and `config`.
  Errors use {project:'ripple',request_id,error:{code,message,retryable}}, which satisfies both the
  legacy and the public contracts.
- `operations.ts`: the four GuardSpecs. **T02/T04: add `execute` here**; do not bypass runGuarded.
  Legacy fixture mode needs ALLOW_FIXTURE_MODE=true, a localhost host and no VERCEL env. It is unbilled.
  Live legacy requests are billable.
- `quota.ts`: `QuotaStore` interface + `upstashQuotaStore` (reference Lua EVAL; defaults
  100/day global, 40/day per visitor, 12/minute per visitor, overridable via RIPPLE_*RUNS* env).
- `session.ts`: `ripple_visitor` = `<22-char id>.<HMAC>`; HttpOnly, SameSite=Strict, Path=/,
  180 days, and Secure when the request is HTTPS. The MCP bridge regex accepts it.
- `config.ts`: lazy env reads (importing it does no I/O or network). `health.ts` returns the legacy
  fields plus public_beta/safety/limits/source_hosts/simulation_lab and no secrets.
- `/api/session` GET returns {ok:true} and the cookie, or 503 if the signing secret is missing.

## Unresolved / for the controller
- Local `.env.local` has an EMPTY UPSTASH_REDIS_REST_URL and RIPPLE_STATE_SECRET, and
  RIPPLE_PUBLIC_BETA=false. So health reports public_beta:false, /api/session returns 503, and
  billable routes will return 503 until configure-ripple-public.py supplies the values. Telem and
  model keys are present.
- Health has public-beta fields beyond the legacy health.schema.json (which sets
  additionalProperties:false). API.md requires those fields; all legacy required fields are present.
- Not verified on Vercel yet: the assumption that Host/x-forwarded-proto give the public origin.
  Check this after the first deployment (browser gate `cross_origin_rejection` plus a real create).
